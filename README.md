# AppUapHuBrasil

Sistema de Ferramentas Administrativas da **UAP/Divgp** (Unidade de Administração de Pessoal / Divisão de Gestão de Pessoas)  
**HU Brasil – Hospital Universitário Lauro Wanderley **

## Ferramentas disponíveis

| Ferramenta | Descrição |
|---|---|
| Calculadora de Mesa | Operações matemáticas rápidas |
| Cálculo de Reposição | Apuração de valores de reposição ao erário |
| Parcelamento de Reposição | Gestão de parcelamento de valores |
| Licença Maternidade | Cálculo e dedução de Salário Maternidade |
| Calculadora IRPF | Simulador de Imposto de Renda Pessoa Física |
| Calculadora INSS | Contribuição INSS com tabela progressiva 2026 |
| 13º Salário e Férias | Apuração de 13º salário e férias |
| Média de Férias | Cálculo de média de variáveis (Rubrica 00393) |
| Adicional Noturno | Cálculo do adicional noturno (Rubrica 00411) |
| Horas Extras 50% | Adicional por serviço extraordinário (Rubrica 00081) |
| Horas Extras 100% | Horas extras em domingos e feriados (Rubrica 00361) |
| Horas Feriado | Remuneração em dobro por trabalho em feriados |
| Desconto de Faltas | Dedução por faltas (Base 00211) |
| Desconto de Horas Expiradas | Desconto salarial por horas não cumpridas |
| FGTS | Cálculo de FGTS |
| Terço de Férias | Terço de férias com INSS progressivo |
| Parcelamento (Item 9) | Cálculo conforme critérios do Item 9 |
| Ajuste Financeiro Retroativo | Desconto proporcional por dias |
| Calculadora de Horas | Soma e subtração de horas |
| Juntar PDFs | União de múltiplos arquivos PDF |
| Controle de Processos | Acompanhamento de processos |
| Notificação por E-mail | Envio de notificações |

## Tecnologias

- HTML5 + CSS3 + JavaScript puro (sem frameworks)
- [jsPDF](https://github.com/parallax/jsPDF) – exportação para PDF
- [SheetJS (xlsx)](https://sheetjs.com/) – exportação para Excel
- [html2canvas](https://html2canvas.hertzen.com/) – captura de tela
- Google Fonts (Inter)

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.  
Não é necessário servidor web ou instalação de dependências.
